Описание программы «Трекер тренировок»
Автор
Антон Гунов

Краткое описание программы
Программа «Трекер тренировок» представляет собой десктопное приложение с графическим интерфейсом на Python (библиотека Tkinter). Она предназначена для учёта физических нагрузок и позволяет:
Добавлять тренировки с указанием даты, типа тренировки (произвольный текст) и длительности в минутах.
Просматривать все добавленные тренировки в виде таблицы.
Фильтровать тренировки по типу (поиск по части слова, регистр не важен) и по точной дате.
Удалять выбранные тренировки.
Вручную сохранять данные в JSON-файл и загружать из JSON-файла.
Программа проверяет корректность ввода: дата должна быть в формате ДД.ММ.ГГГГ, длительность – положительное число. Это помогает избежать ошибок при заполнении.
Данные сохраняются только по команде пользователя (автосохранение отсутствует), благодаря чему можно безопасно экспериментировать с разными наборами записей.

Инструкция по запуску
Требования (зависимости)
Для работы программы необходим Python версии 3.6 или выше. Используются только модули из стандартной библиотеки, поэтому дополнительных установок не требуется.

Установка
Убедитесь, что Python установлен.
Откройте терминал (командную строку) и выполните:

bash
python --version
Если версия 3.6+, всё в порядке. Если Python не установлен, скачайте его с официального сайта (при установке отметьте галочку «Add Python to PATH»).

Скачайте файлы программы.
Сохраните файл main.py (код ниже) в любую удобную папку.

(Опционально) Создайте виртуальное окружение.
Это хорошая практика, но необязательно:

bash
python -m venv venv
source venv/bin/activate   # Linux/macOS
venv\Scripts\activate      # Windows
Запуск
Перейдите в папку с программой через терминал:

bash
cd /путь/к/папке/с/program
Выполните команду:

bash
python main.py
Пример для Windows:

cmd
C:\Users\YourName\Desktop\tracker> python main.py
После этого откроется графическое окно программы.

Примеры использования и работы программы
Пример 1: Добавление первой тренировки
Заполните поля в верхней панели:
Дата: 15.05.2026
Тип тренировки: Утренняя пробежка
Длительность: 35
Нажмите кнопку «Добавить тренировку».
В таблице появится новая строка:
text
15.05.2026  |  Утренняя пробежка  |  35
Пример 2: Добавление нескольких записей
Добавьте ещё две тренировки:
20.05.2026, Плавание, 45
22.05.2026, Велосипед, 60
Теперь в таблице будет три записи.
Пример 3: Фильтрация по типу
В блоке «Фильтр» в поле «Тип тренировки» введите: бег (или пробежк).
Нажмите «Применить фильтр».
Таблица покажет только те записи, в типе которых встречается подстрока «бег» или «пробежк» (например, «Утренняя пробежка»), независимо от регистра букв.
Пример 4: Фильтр по дате
Очистите фильтр кнопкой «Сбросить фильтр».
В поле «Дата» фильтра введите 22.05.2026.
Нажмите «Применить фильтр».
Таблица покажет только одну запись – тренировку на велосипеде.
Пример 5: Комбинированный фильтр
В фильтре укажите:
Тип: плавание
Дата: 20.05.2026
Нажмите «Применить фильтр».
Результат – только запись «Плавание» от 20 мая 2026.
Пример 6: Ошибка ввода
Попробуйте добавить тренировку с некорректной датой, например: 15/05/2026.
Программа покажет сообщение об ошибке:
Неверный формат даты. Используйте ДД.ММ.ГГГГ
Если указать длительность -20 или abc – появится сообщение:
Длительность должна быть положительным числом
Запись не будет добавлена.
Пример 7: Удаление тренировки
Выберите любую строку в таблице, щёлкнув по ней мышью (строка выделится).
Нажмите кнопку «Удалить выбранную тренировку».
Запись исчезнет из таблицы (и из внутреннего списка программы).
Пример 8: Сохранение и загрузка данных
Сохранение:
Нажмите «Сохранить в JSON (по умолчанию)» – все текущие тренировки сохранятся в файл workouts.json в папке с программой.
Или нажмите «Сохранить как...», чтобы выбрать другое имя и место.
Загрузка:
Закройте программу и откройте заново – таблица будет пустой (автозагрузки нет).
Нажмите «Загрузить из JSON (по умолчанию)» – появятся ранее сохранённые записи из workouts.json.
Или «Загрузить из...» – чтобы загрузить произвольный JSON-файл.
Пример 9: Итоговый сценарий работы
Пользователь хочет вести учёт тренировок за неделю:
Запускает программу (python main.py).
Добавляет тренировки за понедельник, среду и пятницу.
Использует фильтр «бег», чтобы посмотреть только беговые тренировки.
Сохраняет все данные в workouts.json кнопкой «Сохранить в JSON».
На следующий день запускает программу снова, загружает данные и продолжает добавлять новые записи.
Возможные проблемы и решения
Проблема	Решение
При запуске ошибка ModuleNotFoundError: No module named 'tkinter'	Tkinter входит в стандартную библиотеку Python. Если ошибка возникает, переустановите Python с включённым компонентом tcl/tk (на Windows – отметьте «tcl/tk» при установке).
Не сохраняется файл workouts.json	Убедитесь, что у программы есть права на запись в папку. Запустите терминал от имени обычного пользователя (не администратора).
Не загружается файл – ошибка формата JSON	Файл повреждён. Удалите его и сохраните данные заново, либо загрузите другой корректный файл.
Примечание
Программа разработана в учебных целях и может быть расширена: добавление редактирования записей, экспорт в CSV, статистика по тренировкам и т.д.
